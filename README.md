# Mental Health Patterns in Canada and the United States, 2000–2021

**A Multivariate Analysis Using R**

**Author:** Abbas Ali

## Overview

This project examines mental health patterns in **Canada and the United States from 2000 to 2021** using multivariate statistical analysis in R. The analysis explores relationships among mental health indicators across the two countries and investigates how these patterns changed over time.

## Research Objectives

The project aims to:

* Compare mental health patterns in Canada and the United States.
* Examine changes in mental health indicators between 2000 and 2021.
* Apply multivariate statistical methods to identify important patterns and relationships.
* Demonstrate reproducible data analysis using R and R Markdown.

## Methods

The analysis was conducted using **R** and **R Markdown**. Statistical and graphical methods were used to examine trends, relationships, and differences in mental health indicators between Canada and the United States.
